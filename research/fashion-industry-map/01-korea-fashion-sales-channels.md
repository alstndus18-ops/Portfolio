# 국내 패션 유통·판매 채널 구조

작성일: 2026-10-26  
상태: 1차 산업 지도. 대표 구조를 먼저 정리하며, 사업자 전체 목록은 이후 별도 DB로 확장한다.

## 1. 이 문서가 답할 질문

국내 의류 상품은 누가 기획·생산하고, 어떤 판매 경로를 거쳐 소비자에게 닿는가?  
같은 브랜드라도 여러 채널에서 동시에 팔릴 수 있으므로, 브랜드와 판매 채널을 구분해 기록한다.

```text
제조·사입·브랜드
        ↓
자사몰 / 패션 플랫폼 / 종합 온라인몰 / 백화점·아울렛 / 편집숍 / 홈쇼핑 / 오프라인 매장
        ↓
소비자
```

## 2. 채널별 기본 지도

| 채널 | 역할 | 주로 만나는 사업자 | MD 관점에서 볼 점 |
| --- | --- | --- | --- |
| 공식 자사몰 | 브랜드가 고객·상품·프로모션을 직접 운영 | 패션기업, 디자이너 브랜드, 자체제작 쇼핑몰 | 신상품 주기, 회원 혜택, 정상가·할인가, 기획전 |
| 패션 플랫폼 | 여러 브랜드·판매자를 모아 탐색·구매를 돕는 전문 채널 | 입점 브랜드, 셀러, 플랫폼 운영사 | 입점 브랜드 구성, 랭킹, 쿠폰, 수수료 구조, 노출 방식 |
| 종합 온라인몰·오픈마켓 | 패션 외 상품도 함께 판매하는 온라인 장터 | 브랜드, 개인 판매자, 스마트스토어 운영자 | 검색광고, 배송, 가격 경쟁, 판매자 구조 |
| 백화점 | 브랜드 신뢰도와 오프라인 체험을 제공하는 고급 유통 채널 | 국내외 브랜드, 백화점 바이어 | 매장 위치, 시즌 행사, 브랜드 구성, 온라인 연계 |
| 아울렛 | 이월상품·할인상품 판매 비중이 큰 오프라인 유통 채널 | 브랜드, 유통사 | 할인율, 재고 소진, 가격 정책 |
| 편집숍 | 운영자가 고른 여러 브랜드를 큐레이션해 판매 | 디자이너·독립 브랜드, 바이어 | 선택 기준, 브랜드 조합, 콘텐츠·스타일 제안 |
| 홈쇼핑·라이브커머스 | 방송·라이브 콘텐츠로 상품을 설명하며 판매 | 브랜드, 제조사, 방송·플랫폼 사업자 | 방송 구성, 세트 상품, 시간 한정 혜택, 반품 정책 |
| 동대문 도매·사입 | 도매 상품을 소매 쇼핑몰·매장에 공급하는 기반 | 도매상, 사입자, 보세 쇼핑몰 | 신상 속도, 최소 수량, 사입 가격, 상품 중복 가능성 |
| 오프라인 단독 매장·팝업 | 상품 체험과 브랜드 경험을 만드는 직접 접점 | 브랜드, 임대·유통 사업자 | 상권, 매장 경험, 팝업 목적, 온라인 전환 연결 |

## 3. 꼭 구분할 네 가지

| 구분 | 뜻 | 예시 관계 |
| --- | --- | --- |
| 기업 | 사업을 운영하는 법인·사업자 | 한 기업이 여러 브랜드를 운영할 수 있음 |
| 브랜드 | 소비자에게 보이는 상품·정체성 단위 | 한 브랜드가 자사몰과 플랫폼에 함께 입점할 수 있음 |
| 쇼핑몰 | 실제 구매가 일어나는 웹사이트·스토어 | 한 쇼핑몰이 여러 브랜드를 판매할 수 있음 |
| 판매 채널 | 소비자에게 닿는 경로 | 온라인 자사몰, 플랫폼, 백화점 매장 등 |

따라서 향후 DB는 `기업`, `브랜드`, `쇼핑몰·매장`, `판매 채널`, `관계`를 나누어 기록한다. 예를 들어 “브랜드 A가 플랫폼 B에 입점”은 브랜드 목록이나 플랫폼 목록에 중복으로 적기보다 관계 데이터로 연결한다.

## 4. 1차 관찰

- 국내 패션 판매는 온라인과 오프라인이 분리된 구조가 아니라, 자사몰·플랫폼·매장·팝업을 함께 운영하는 복수 채널 구조로 보는 편이 맞다.
- 보세·사입 쇼핑몰은 동대문 도매·사입과 연결되는 경우가 많고, 브랜드 자사몰은 자체기획·생산 및 브랜딩과 연결되는 경우가 많다. 실제 운영 방식은 사이트별로 확인한다.
- 같은 상품 또는 유사 상품이 여러 채널에 동시에 노출될 수 있으므로, 가격 비교에는 `정상가`, `판매가`, `쿠폰·회원가`, `배송비`를 구분해서 기록한다.
