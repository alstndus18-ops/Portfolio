# 패션기업 → 브랜드 → 판매 채널: 1차 관계 지도

작성일: 2026-10-26  
범위: 공식 기업 페이지에서 확인 가능한 운영 관계를 정리한 1차 지도다. 개별 브랜드의 실제 판매 채널 입점 여부는 상품·브랜드 페이지로 별도 검증한다.

## 1. 왜 관계를 나누어 기록하는가

아래 세 관계는 비슷해 보여도 서로 다르다.

```text
패션기업 ─운영한다→ 자사 쇼핑몰
패션기업 ─보유·운영한다→ 브랜드
브랜드 ─실제로 판매한다→ 특정 쇼핑몰·플랫폼·매장
```

첫 두 관계가 확인됐다고 세 번째가 자동으로 성립하지는 않는다. 예를 들어 같은 기업이 여러 브랜드와 쇼핑몰을 운영해도, 상품별 판매 여부·재고·가격·입점 시점은 다를 수 있다.

## 3. MD 관점에서 보는 의미

| 관찰 대상 | 확인할 질문 |
| --- | --- |
| 브랜드 포트폴리오 | 한 기업이 어떤 고객층·가격대·카테고리를 동시에 커버하는가? |
| 자사 쇼핑몰 | 그룹 브랜드만 판매하는가, 외부 브랜드도 입점시키는가? |
| 온·오프라인 연결 | 온라인 단독 혜택, 매장 재고, 팝업, 백화점 입점이 어떻게 연결되는가? |
| 아울렛·할인 | 이월상품과 정가 상품을 어느 채널에서 어떻게 분리하는가? |
| 외부 플랫폼 입점 | 자사몰과 무신사·백화점 등 외부 채널의 상품·가격·혜택이 어떻게 다른가? |

## 4. 관계 DB의 기록 규칙

| 관계 | 기록 조건 | 예시 |
| --- | --- | --- |
| `operates` | 운영사가 공식적으로 쇼핑몰·서비스를 운영한다고 밝힘 | 코오롱인더스트리 FnC → 코오롱몰 |
| `owns_or_operates_brand` | 기업이 브랜드 보유·운영을 공식적으로 밝힘 | 삼성물산 패션부문 → 빈폴 |
| `sells_through` | 브랜드 공식 페이지 또는 실제 상품 페이지에서 특정 채널 판매를 확인 | 브랜드 A → 플랫폼 B |
| `has_store_at` | 공식 매장 안내에서 매장·백화점·아울렛 위치를 확인 | 브랜드 A → 백화점 C |

`sells_through`와 `has_store_at`은 개별 확인이 필요하므로, 이번 단계에서는 추정으로 추가하지 않는다.

## 5. 이미 확보한 관계 데이터 활용

기존 `research/fashion-commerce-map/data/curated/korea_relationships.csv`에는 다음과 같은 공식 확인 관계가 들어 있다.

- 삼성물산 패션부문 → SSF샵, 빈폴, 에잇세컨즈, 갤럭시, 구호 등
- 코오롱인더스트리 FnC → 코오롱몰, 더카트, 코오롱스포츠, 래코드, 시리즈, 럭키슈에뜨 등
- 한섬 → 더한섬닷컴, 타임, 시스템, SJSJ, 마인 등
- 이랜드월드 패션사업부 → 스파오닷컴, 이랜드몰, 스파오, 미쏘, 후아유 등
- 엘에프 → LF몰, 헤지스, 닥스, 마에스트로, 질스튜어트 뉴욕 등

이 자료는 **기업이 운영하는 브랜드·쇼핑몰 관계**를 보여 주는 기반 데이터다. 다음 회차부터는 각 브랜드의 외부 플랫폼·오프라인 매장 판매 관계를 별도로 추가한다.

## 7. 바로 다음에 할 수 있는 작업
