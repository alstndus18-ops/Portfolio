# 수집 노하우 (에이전트 공유)

브랜드·쇼핑몰을 모으면서 알게 된 빠른 방법과 시행착오를 모은다. Claude·Codex·Cursor 누구든 **수집 전에 "꼭 지킬 것"과 해당 사이트 방법을 읽고**, 수집 후 새로 알게 된 것을 "시행착오 기록"에 한 줄 추가한다.

- 시행착오 기록은 맨 아래에 추가만 한다. 형식: `날짜 · 에이전트 · 사이트 — 겪은 일 → 원인 → 다음엔`. **1~2줄로 짧게 쓰고, 사이트마다 반복해서 쓸 방법은 "사이트별 메모" 표로 옮긴다.**
- 같은 교훈이 두 번 이상 나오면 "꼭 지킬 것"이나 사이트 방법을 제자리에서 고친다.
- 수집 기준은 기획서 §10(지금은 13·14번)과 `AGENTS.md` 데이터 원칙이 우선한다. 여기는 "어떻게 빠르고 확실하게"만 다룬다.

## 꼭 지킬 것

1. **후보는 목록에서 찾는다.** 브랜드 이름을 떠올리거나 상품을 훑지 말고, 카테고리 필터의 브랜드 목록(facet)부터 본다. 무신사는 이 방법으로 수천 개를 몇 분에 받았다.
2. **범위는 최상위 카테고리 전부를 먼저 센다.** 합집합 수와 범위 밖 수를 같이 구하고, "다 모았다"고 보고할 때 그 숫자를 함께 보여 준다. 범위가 애매하면 넓히기 전에 사용자에게 묻는다.
3. **다 받았는지 확인한다.** 카테고리마다 응답의 전체 수(`totalCount`)와 받은 고유 브랜드 수를 비교하고, 실패한 쪽은 재시도한다.
4. **중복은 플랫폼 브랜드 주소로 먼저 판정한다**(무신사 `/brand/<주소>`). 이름은 보조다. 이름만 같고 주소가 다르면 브랜드 정보(국가·설립)를 비교해 다르면 별개 브랜드로 넣는다.
5. **기준은 목록 대조로 단순하게.** 비율·수식 대신 "그 목록에 있다/없다"로 판단하고, 제외도 목록 대조로 한다(속옷 전용, 상품 0개).
6. **확인 안 한 값은 채우지 않는다.** 국가 등은 플랫폼 브랜드 정보에 있을 때만 적는다.
7. **CSV는 검사하고 쓴다.** 쓰기 전에 넣을 줄 수를 `throw`로 검사하고 분류(`primary_category`)별 개수를 출력해 본다. 쓴 뒤 `git diff --numstat`. 잘못 썼으면 커밋 전에 `git checkout -- <CSV>`로 되돌리고 다시 쓴다(자기 변경만 있을 때).
8. **PowerShell 5.1 함정.** 변수 대소문자를 구분하지 않는다(`$e`와 `$E`는 같은 변수, 반복 변수는 `$row`처럼 전혀 다른 이름). `… | ConvertFrom-Json | Where-Object`는 배열을 한 덩어리로 넘기므로 변수에 담고 `foreach`. 점검 스크립트에서도 같다.
9. **agent-browser.** 열고 나서 `get url`로 확인, 스크립트는 base64(`eval -b`), 10초 넘는 조회는 페이지 안 백그라운드 실행 후 짧은 확인으로 가져온다. 브라우저 밖 직접 요청은 막히며(무신사 403), 로그인·차단을 우회하지 않는다.
10. **Git.** 시작할 때 `git pull`, 커밋 전 `git fetch`. 원격 변경과 겹치는 파일이 `STATUS.md`뿐이면 양쪽 내용을 살려 합치고, 데이터·기획 파일이 겹치면 사용자에게 묻는다.

**실행 요령 (PowerShell + agent-browser)**

- 명령줄 한도(약 32,000자) 때문에 base64가 3만 자를 넘지 않게 나눈다. 수천 개면 `window.__s=window.__s.concat([...])`로 800~1,000개씩 페이지에 먼저 넣고, 백그라운드 스크립트가 `window.__s`를 읽게 한다.
- 요청은 4~8개씩 `Promise.all`로 묶는다. 브랜드당 2번(성별 수·브랜드 정보) × 3,068개가 73초.

```powershell
function ABEval($js) { $b = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($js)); (agent-browser eval -b $b 2>$null) -join "`n" }
# 백그라운드 시작: $slugs = "'kirsh','urago',..."
ABEval "window.__r=null;(async()=>{const s=[$slugs];const out={};for(let i=0;i<s.length;i+=8){await Promise.all(s.slice(i,i+8).map(async b=>{const r=await fetch('https://api.musinsa.com/api2/dp/v1/plp/goods/count/gender?gf=A&brand='+b+'&caller=FLAGSHIP',{credentials:'include'});if(r.ok)out[b]=(await r.json()).data}))}window.__r=JSON.stringify(out)})();'started'"
# 끝날 때까지 한 명령 안에서 기다린 뒤 가져오기
for ($k=0; $k -lt 40; $k++) { Start-Sleep 3; if ((ABEval "window.__r?'done':'run'") -match 'done') { break } }
$res = ((ABEval "window.__r") | ConvertFrom-Json) | ConvertFrom-Json
```

브랜드 정보 추출 (공백·줄바꿈이 섞여 있으므로 정규식에 `\s*`):

```js
const meta=async b=>{const h=await (await fetch('/brand/'+encodeURIComponent(b)+'/products?gf=A')).text();const m=/meta:\s*(\{[\s\S]*?\})\s*,\s*shared:/.exec(h);if(!m)return null;const d=JSON.parse(m[1]);return {ko:d.brandName,en:d.brandNameEng,nation:d.brandNation,nationName:d.brandNationName,since:d.since}};
```
