# 10. 보세 의류 쇼핑몰 발견 기준 (초안)

## 대상

- 국내 여성 중심 온라인 의류 쇼핑몰, 특히 자체 기획·저가 의류 위주의 보세 쇼핑몰
- 범위는 **전국**. 시도별 공정위 데이터를 모두 대상으로 한다.

## 발견 경로

1. **공정위 통신판매사업자 전국 데이터**: 상호명·업종 키워드로 1차 후보를 거른다.
2. **검색 키워드**: 여성의류쇼핑몰, 데일리룩, 신상 등. 광고 결과와 일반 결과를 구분해 기록한다.
3. **플랫폼 입점 판매자**: 여성 의류를 주로 파는 판매자의 공개 페이지 기준.
4. **기존 목록 교차**: `data/curated/korea_shopping_malls.csv`와 대조해 중복을 제거한다.

## 포함 기준 (모두 충족)

- 사이트가 존재하고 접속된다.
- 의류(상의·하의·아우터 등)가 주력 상품이다.
- 국내 소비자를 대상으로 한국어로 판매한다.
- 여성 고객이 주 타깃이다. 남녀 공용은 별도 태그로 구분한다.

운영 주체 정보(사업자명, 통신판매 신고번호)는 포함 조건이 아니다. 확인되면 기록한다 (기획서 §10-9). 이 기준이 기획서 §5-3과 다르면 기획서가 우선한다.

## 수집하지 않는 경우

- 공정위나 다른 목록에 있어도, 그 이름의 사이트가 없거나 쇼핑몰이 운영되지 않으면 정보를 수집하지 않는다.
- 잡화·화장품 등 의류가 아닌 상품만 판매하면 수집하지 않는다.
- 접근 제한을 우회해야만 정보를 얻을 수 있으면 수집하지 않는다.

## 최소 기록 항목

| 항목 | 설명 |
| --- | --- |
| 쇼핑몰명 | 표시명 |
| 도메인 | 기준 키. 상호는 자주 바뀌므로 도메인으로 식별한다. |
| 운영사 | 사업자명 (확인되지 않으면 비움) |
| 발견 경로 | 공정위 / 검색 / 플랫폼 / 기존 목록 |
| 확인일 | 마지막으로 사이트를 확인한 날짜 |
| 메모 | 자유 기록 |

## 주의

- 공정위 원본에는 대표자명, 전화번호, 주소 등 개인정보가 있다. 원본은 로컬에만 두고, 저장소에는 상호·도메인·집계 중심으로 기록한다.
- 검색 광고 결과는 노출이 돈으로 산 결과이므로, 운영 지속성의 근거로 쓰지 않는다.
- 쇼핑몰은 생기고 사라지는 속도가 빠르므로, 확인일을 반드시 남긴다.
