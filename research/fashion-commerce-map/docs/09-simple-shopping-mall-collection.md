# 단순 쇼핑몰 수집 기준

지금 단계의 목적은 복잡한 기업 구조를 만드는 것이 아니라, 국내 쇼핑몰을 넓게 발견하고 비교 가능한 목록으로 쌓는 것이다.

## 쇼핑몰 목록에 남기는 정보

1. 쇼핑몰명
2. 사이트 주소
3. 큰 카테고리
4. 사이트가 내세운 스타일·타깃 키워드
5. 발견한 네이버 검색어
6. 상태 (임시, 아래 상태 원칙)
7. 한 줄 메모

## 키워드는 두 종류를 구분한다

- `discovery_queries`: 그 쇼핑몰을 찾기 위해 실제로 사용한 네이버 검색어
- `site_keywords`: 검색 결과 또는 해당 사이트가 드러낸 상품·스타일·타깃 키워드

따라서 나중에 “빅사이즈”를 검색해 발견한 몰과, 사이트 안에서 “빅사이즈”를 내세우는 몰을 각각 구분해서 볼 수 있다.

## 상태 원칙

- 목록에는 사이트 접속과 운영을 확인한 곳만 남긴다 (기획서 §5-4).
- 지금 `status` 열의 `확인 필요`·`확인 실패`·`발견`은 남은 확인 대상이다. 모두 확인해 남기거나 지운 뒤 `status` 열을 없앤다 (기획서 §10-8).

운영 회사, 매출, 입점 채널 등은 필요한 쇼핑몰에 한해서만 후속 조사한다.
