# 매일 추적하기 (며칠치 변화 보기)

확정 4곳(쿠메·낫띵리튼·쉬즈미스·제이제이지고트)과 그레이스유를 **같은 시각에 매일 한 번** 읽어 날짜별 스냅샷으로 쌓고, 날짜 사이 변화를 비교한다. 5일 정도 쌓으면 신상 주기·할인 시작/종료·품절 변화·가격 변경이 보인다.

## 한 번에 돌리기

```bash
tools\run_daily.cmd
```

(Windows. 필요한 것: Python 3.12, `agent-browser` CLI. Python 경로는 `%LOCALAPPDATA%\Programs\Python\Python312\python.exe`로 가정. 다르면 파일 맨 위 `PY=` 줄만 고친다.)

돌리는 내용과 걸리는 시간(대략 10~15분):

| 단계 | 대상 | 결과 파일 |
|---|---|---|
| 공식몰 전체 상품 | 쿠메(카페24) · 쉬즈미스(IDF몰) · 낫띵리튼 · 제이제이지고트(바바더닷컴) | `snapshots/official/<브랜드>/<날짜>.json` |
| 29CM 브랜드 페이지 | 쿠메·낫띵리튼·쉬즈미스·제이제이지고트 | `snapshots/29cm/<ID>/<날짜>.json` |
| W컨셉 브랜드관 | 그레이스유·쿠메·낫띵리튼·제이제이지고트 | `snapshots/wconcept/<ID>/<날짜>.json` |

같은 날 다시 돌리면 그날 파일을 덮어쓴다. 로그인·장바구니·주문은 건드리지 않고, 요청 사이 1초 쉰다.

## 변화 보기

```bash
python tools/diff_snapshots.py official kume                 # 가장 최근 두 날짜 비교 (신상·삭제·가격·품절)
python tools/diff_snapshots.py official kume 2026-10-29 2026-11-02
python tools/diff_snapshots.py official --all --series       # 4곳 지표 추이 표(상품수·정가중앙·판매가중앙·할인비율·품절)
python tools/diff_snapshots.py 29cm 1939 --series
python tools/diff_snapshots.py wconcept 108809 --series
```

## 읽을 때 알아야 할 것

- 공식몰 스냅샷은 **상품 단위**(이름·정가·판매가·할인율·품절·배지·목록 순서)다. 목록 순서(`pos`)가 바뀌면 진열 순서(신상·인기)가 바뀐 것이다.
- **품절은 쿠메·쉬즈미스 목록 HTML에서 읽히지 않는다(0건).** 두 몰은 목록에 품절 표시를 넣지 않는 것으로 보인다. 품절 변화를 보려면 상품 상세의 옵션 재고를 읽는 단계를 추가해야 한다.
- 29CM·W컨셉 스냅샷은 **브랜드 페이지 첫 화면 상품 카드**(최대 약 50~190개)다. 전체 상품 수가 아니다.
- 낫띵리튼 공식몰은 현재 시즌(293~304)·세일·재입고·아웃렛과 상의·니트 지난 시즌 목록만 읽는다. 다른 지난 시즌 아우터·하의는 빠진다.
- 바바더닷컴은 그룹몰이다. 사이트가 표시하는 `total`(484 등)과 읽은 수를 비교해 두었다.
- 스냅샷은 시각이 아니라 **날짜** 단위다. 하루에 두 번 돌릴 필요는 없다.

## 매일 자동으로 돌리고 싶을 때

이 PC가 켜져 있어야 한다. 작업 스케줄러에 `tools\run_daily.cmd`를 매일 같은 시각으로 등록하거나, Claude에게 예약 작업으로 만들어 달라고 요청한다(요청 전에는 만들지 않는다).
