# 재질 데이터 분리 작업

이 폴더는 `similar-search` 화면 본체와 분리해, 기존 상품에 재질 정보를 붙인 뒤 Cursor 작업이 끝나면 합치기 위한 중간 결과다.

## 현재 상태와 남은 일 (2026-10-27, 진행 중)

혼용률 확보: 468개 중 303개. 데이로제 96/100, 사라172 93/100, 블루팝스 78/100, 메이홀릭 36/100, 모어모먼트 0/68.
`material-records.csv`의 `product_id`는 현재 `data.js`의 상품 468개와 모두 일치한다.

1. 메이홀릭 빈값 64개 재확인: 표본 10개는 모두 DOM `상세정보 > 소재`에서 찾았으므로 전수 추출이 덜 된 것으로 보인다(추정).
2. 블루팝스 빈값 22개: 규격표 OCR 미인식 사례가 있어(`bluepops-53350`) 재-OCR 또는 수동 확인.
3. 메이홀릭 `FABRIC`·하단 소재 충돌: 지금 CSV에는 충돌을 남길 칸이 없다. 칸을 추가할지 정한다.
4. 화면 병합: 아직 안 함. `tools/analyze.py`가 이 CSV를 읽어 상품에 `material`(아래 병합 기준 구조)을 붙이고, `index.html` 상세 칸에 표시한다.

OCR 재실행(`tools/extract_material_ocr.py`)은 `easyocr`와 `cache/`의 상세 이미지가 필요하다. `cache/`는 저장소에 없으므로 먼저 `tools/collect.py`를 돌린다.

몰별 탐색 순서와 새 예외는 `mall-extraction-rules.json`에 누적한다. 재질 작업을 맡는 AI는 이 파일을 먼저 읽고, 반복되는 예외는 `learning_log`와 `steps`에 함께 반영한다.

## 확정 의도

- 기록 항목은 `주원단`, `혼용률`, `원단 형태`, `가공/특징` 네 가지다.
- 값은 **상품명, 상세 페이지의 텍스트, 상세 이미지 안에 인쇄된 상품 규격표의 텍스트**에서만 읽는다.
- 상세 이미지의 `소재: 폴리 62%, 레이온 33%, 스판 5%`처럼 사람이 읽는 공식 표는 OCR/텍스트 추출로 읽을 수 있다. 이는 이미지의 옷 모습에서 재질을 추정하는 분석과 다르다.
- 상품 사진의 색·질감·짜임·두께·모양을 AI가 보고 재질, 원단 형태, 가공을 추정해서 넣지 않는다.
- 명시된 혼용률이 없으면 주원단도 추정하지 않는다.
- `니트`, `골지`, `기모`처럼 명시된 원단 형태/가공만 태그로 넣고, 사진 판정으로 추가하지 않는다.
- 겉감·안감·충전재가 따로 있으면 지금은 겉감만 기록한다. 상세페이지가 구분하지 않으면 섞어 쓰지 않는다.

## 병합 기준

`material-records.csv`는 현재 `data/products_raw.json`의 468개 상품과 같은 수의 행을 가진다. `product_id`는 원본의 `id`와 같다.

- 5개 몰의 현재 등록 상품 468개를 확인했다. DOM 텍스트 225개와 블루팝스 공식 규격표 OCR 78개, 총 303개의 `primary`·`composition`을 채웠다.
- `fabric_forms`·`finishes`는 상품명에 해당 단어가 실제로 있을 때만 넣었다. 전체 사진을 보고 추정한 값은 없다.
- 나머지 빈 `primary`·`composition`은 상세페이지 텍스트와 공식 규격표 OCR에서 아직 확인되지 않은 값이다. 블루팝스는 규격표가 있어도 OCR 미인식 사례가 확인됐으므로 빈값을 소재 부재로 확정하지 않는다. 모어모먼트 68개는 두 경로를 모두 확인했으나 명시 혼용률이 없었다. 옷 사진 분석·사진 추정으로 채우지 않는다.
- 공식 DOM이 `면 66%`처럼 일부만 표기한 경우는 원문을 그대로 보존하되, 나머지 혼용률을 추정해 채우지 않는다.

### 모어모먼트 확인 메모

`멀티웨이 컷 아웃 티셔츠`, `캐시 울 브이넥 니트`의 하단 `SIZE → MODEL SIZE → WASHING INFO → PRODUCTION`은 실제 DOM 텍스트다. 다만 `WASHING INFO`의 “원단 상태 유지”, “데님 및 색상 원단”은 모든 상품에 공통으로 붙는 세탁 안내이며, 해당 상품의 소재·혼용률 표기가 아니다. 따라서 이 문구에서 면·데님·원단 같은 단어를 재질 필드로 뽑지 않는다.

Cursor는 이 키로 `data.js`의 동일 상품에 아래 구조를 합치면 된다.

```json
{
  "material": {
    "primary": "레이온",
    "composition": "레이온 96%, 스판 4%",
    "fabricForms": ["골지"],
    "finishes": ["기모"]
  }
}
```

CSV의 빈 문자열과 빈 배열은 ‘상세페이지의 허용된 텍스트 경로 또는 상품 규격표에서 확인하지 못함’이며, 옷 사진 분석이나 상품명 추정으로 채우지 않는다.
