# Global Fashion Commerce Map

패션 커머스의 회사, 법인 판매자, 브랜드, 쇼핑몰·플랫폼, 판매 채널을 **근거와 확인 시점**까지 남기며 연결하는 조사형 데이터베이스 프로젝트입니다.

처음에는 한국을 검증 가능한 첫 시장으로 구축하고, 같은 데이터 구조를 유지한 채 국가별로 확장합니다.

## 프로젝트 원칙

- "전 세계 전체"나 "모든 쇼핑몰"을 완결된 사실처럼 주장하지 않습니다.
- 각 레코드는 출처, 확인 일시, 검증 상태, 적용 범위를 남깁니다.
- 회사·판매자·브랜드·쇼핑몰·입점 계정은 서로 다른 개체로 다룹니다.
- 공개적으로 접근 가능한 정보와 각 서비스의 이용 조건을 존중합니다. 로그인 우회나 접근 제한 우회는 하지 않습니다.
- 원본 수집 자료와 정제된 공개 데이터를 분리합니다.

## v0.1 범위 — 대한민국

초기에는 주요 패션 플랫폼, D2C 쇼핑몰, 브랜드를 중심으로 아래 정보를 구조화합니다.

- 운영 회사 또는 신고 판매자
- 브랜드와 브랜드 원산지
- 쇼핑몰·플랫폼과 판매 채널
- 상품 카테고리, 가격대, 핵심 타깃
- 관계의 근거와 확인 일시

자세한 범위와 제외 기준은 [프로젝트 범위](docs/00-project-scope.md)를 봅니다.

## 폴더 구성

```text
docs/              조사 기준, 데이터 모델, 분류 체계, 의사결정 기록
research/          조사 메모와 후보 목록 (근거를 잃지 않는 작업 공간)
data/raw/          재배포 조건을 확인한 원본·추출 자료 (기본적으로 커밋하지 않음)
data/curated/      출처와 검증 상태가 명확한 정제 데이터
```

## 시작 순서

1. [프로젝트 범위](docs/00-project-scope.md)에서 이번 조사에 포함할 대상을 확정합니다.
2. [데이터 모델](docs/01-data-model.md)에 따라 레코드를 만듭니다.
3. [출처 등록부](docs/02-source-register.md)에 출처와 사용 조건을 기록합니다.
4. [분류 체계](docs/03-taxonomy.md)를 필요한 만큼만 보완합니다.
5. 중요한 해석이나 범위 변경은 [의사결정 기록](docs/04-decision-log.md)에 남깁니다.
6. 국내 전수 조사 진행 상황은 [수집 운영 모델](docs/05-korea-collection-operating-model.md)과 [`korea_coverage.csv`](data/curated/korea_coverage.csv)에서 관리합니다.
7. 조사 대상 분류와 상세 수집 순서는 [한국 조사 카탈로그](docs/06-korea-research-catalog.md)를 기준으로 관리합니다.

## 현재 상태

기초 설계 단계입니다. 아직 "전수 목록"이나 확정된 경쟁사 관계를 제공하지 않습니다.
