# 패션 이커머스 실무 지식 모음 (참고)

작성: 2026-10-27 · 상태: **참고 자료다. 결정이 아니다.** [이론·기법 참고서](analysis-theory-reference.md)가 "무슨 이론이 있는가"라면, 이 문서는 패션 온라인몰을 실제로 운영할 때 쓰는 지표, 업무 흐름, 규정, 경쟁 신호 해석을 모았다. 우리 수집 데이터로 무엇을 할 수 있는지는 [다음 자료 제안](next-materials-proposal.md)에 있다.

**읽는 법**

- 숫자는 계산법을 보이는 **예시값**이다. 업계 평균이나 실제 시장 값이 아니다. 업계 벤치마크 수치는 출처를 확인하기 전에는 쓰지 않는다.
- 법·규정은 일반적으로 알려진 내용을 정리한 것이다. **적용 전에 최신 법령과 공정거래위원회 안내를 확인**한다.
- "공개 정보"는 경쟁사 사이트에서 보이는 정보를 뜻한다.

## 1. 핵심 지표 사전

지표는 정의가 같아야 비교된다. 같은 이름이라도 분모가 다르면 값이 다르다.

| 지표 | 공식 | 예시값 | 주의 |
| --- | --- | --- | --- |
| 전환율 | 구매 세션 ÷ 전체 세션 | 300 ÷ 10,000 = 3.0% | 세션 대신 방문자로 나누면 값이 달라진다 |
| 객단가(AOV) | 매출 ÷ 주문 수 | 13,500,000 ÷ 300 = 45,000원 | 환불 전·후 중 무엇인지 적는다 |
| 주문당 상품 수(UPT) | 판매 수량 ÷ 주문 수 | 540 ÷ 300 = 1.8개 | 무료배송 기준 설계에 쓴다 |
| 장바구니 이탈률 | 1 − 결제 수 ÷ 장바구니 생성 수 | 1 − 300 ÷ 900 = 66.7% | 이탈 원인(배송비·쿠폰)을 함께 본다 |
| 반품률 | 반품 건수 ÷ 출고 건수 | 60 ÷ 300 = 20% | 금액 기준과 건수 기준을 구분한다 |
| 재구매율 | N일 내 재구매 고객 ÷ 기간 내 첫 구매 고객 | 90일: 24 ÷ 120 = 20% | 기간을 반드시 적는다 |
| 신규 대 재구매 매출 비중 | 재구매 고객 매출 ÷ 전체 | 40% | 광고 의존도를 보여준다 |
| 마케팅 효율(MER) | 전체 매출 ÷ 전체 마케팅비 | 1억 ÷ 2,500만 = 4.0 | 채널별 귀속 없이 전체로 본다 |
| 광고 수익률(ROAS) | 광고 매출 ÷ 광고비 | 3.2 | 손익분기 ROAS = 1 ÷ 공헌이익률 |
| 재고 판매율 | 판매 ÷ (기초+입고) | 70% | 시즌 종료 시점 기준으로 비교 |

## 2. 머천다이징

### 2.1 시즌 캘린더

패션은 "언제 무엇을 파는가"가 매출을 좌우한다. 아래는 한국 소비자 달력에서 흔히 쓰는 구분이고, 기간은 해마다 다르다.

| 구간 | 상품 흐름 | 마케팅 포인트 |
| --- | --- | --- |
| 1~2월 | 겨울 정리, 봄 신상 선출시, 졸업·입학 | 겨울 재고 할인, 간절기 아우터 예고 |
| 3~4월 | 봄 간절기 | 재킷·가디건·트렌치, 하객룩 |
| 5~6월 | 초여름, 하객·행사 철 | 린넨·반팔, 휴가 준비 |
| 7~8월 | 여름 시즌, 수영복, 가을 선출시 | 시즌 세일, 가을 신상 예고 |
| 9~10월 | 가을 간절기, 추석 이후 | 니트·재킷, 겨울 아우터 선출시 |
| 11~12월 | 겨울 아우터, 연말, 대형 쇼핑 행사 | 연말 모임룩, 대형 할인 행사 경쟁 |

**활용**: 경쟁사의 월별 등록 수와 카테고리 구성을 이 달력과 겹쳐서 "시즌 선출시를 몇 주 앞서 하는가"를 본다. 블루팝스의 2026년 7월 등록 급증(수영복)은 이 구간의 전형적인 일괄 등록이다.

### 2.2 선출시와 시즌 앞당김

- **개념**: 소비자가 사려는 시기보다 4~8주 앞서 신상을 올려 노출과 예약 구매를 확보하고, 시즌 중반에는 추가 발주(리오더)로 인기 상품을 보충한다.
- **측정(공개 정보)**: 시즌 상품의 첫 등록월 대비 해당 시즌 실제 판매 시기 차이. 경쟁사별로 어느 몰이 선출시를 주도하는지 비교한다.

### 2.3 카테고리 역할

머천다이징 이론에서는 카테고리마다 역할을 줘서 자원을 배분한다(Corstjens & Corstjens 1995 등, 카테고리 관리 문헌).

| 역할 | 목적 | 예 |
| --- | --- | --- |
| 목적 방문 | 이 카테고리 때문에 온다 | 대표 아이템(자체제작 원피스) |
| 일상 | 반복 구매 | 기본 티셔츠, 속옷 |
| 시즌 | 시기 한정 | 수영복, 아우터 |
| 편의 | 함께 담기 | 양말, 잡화 |

**활용**: 경쟁사 홈 화면과 카테고리 메뉴 순서를 보면 어떤 카테고리를 목적 방문으로 밀고 있는지 알 수 있다.

### 2.4 사이즈 커브

- **개념**: 사이즈별 판매 비중이 다르므로 발주도 사이즈별 비중을 맞춘다.
- **예시값**: 발주 300장 중 S 20%, M 40%, L 30%, XL 10%이면 60·120·90·30장이다. M이 먼저 품절되고 XL이 남는 일이 흔하므로 이전 시즌 판매 분포로 비율을 정한다.
- **공개 정보로 볼 수 있는 것**: 사이즈 정책(프리, 1·2, 번호, S–XL)과 최대 치수, 사이즈별 옵션 수.
- **한계**: 사이즈별 판매 비중은 자사 데이터만 안다.

### 2.5 상품 수명에 따른 운영

| 단계 | 기간(예) | 가격 | 목표 |
| --- | --- | --- | --- |
| 도입 | 등록 후 0~2주 | 정가·선착순 혜택 | 노출·후기 확보 |
| 성장 | 2~8주 | 정가 유지, 쿠폰 | 판매율 50% 도달 |
| 성숙 | 8~12주 | 쿠폰·묶음 | 회전 유지 |
| 쇠퇴 | 12주 이후 | 단계 할인 | 재고 소진 |

기간은 상품군별로 달라서 일일 기록에서 "첫 할인까지 일수"와 "판매중지까지 일수"를 모아 업계 리듬으로 삼는다.

## 3. 사이즈·핏과 반품

의류 반품의 큰 부분은 사이즈·핏이라는 것이 일반적인 통념이다. 우리 업종의 비율은 자사 데이터로만 확인할 수 있다.

### 3.1 반품 사유 분류

| 사유 | 개선 방향 |
| --- | --- |
| 사이즈 불일치 | 실측 표, 모델 신체 정보, 핏 후기 |
| 색상·질감 차이 | 자연광 사진, 색상 설명, 소재 클로즈업 |
| 상품 불량 | 검수 강화, 협력사 평가 |
| 단순 변심 | 반품 정책 설계, 쿠폰·교환 유도 |

### 3.2 PDP(상품 상세) 정보 체크리스트

경쟁사 상품 상세에서 아래 정보가 있는지 O·X로 기록하면 "정보 충실도 점수"가 된다.

- 모델 키·몸무게·착용 사이즈
- 실측(어깨·가슴·총장·허리 등) 표
- 소재·혼용률, 세탁법, 신축성, 비침, 두께감
- 색상별 사진, 자연광 사진, 디테일 컷
- 사이즈 추천 문구, 후기(사진 후기 비율)
- 배송·교환·반품 안내

**예시값**: 10개 항목 중 8개 충족이면 80점. 몰별 평균을 비교한다.

## 4. 콘텐츠와 전환

### 4.1 상품 페이지가 전환에 영향을 주는 요소

- 대표 이미지: 모델 착용 컷, 배경, 첫 컷 비율
- 가격 표시: 정가·쿠폰가 순서, 할인율 강조 여부
- 사회적 증거: 후기 수, 베스트 표시, 재입고 표기
- 긴급성: "오늘출발", "한정 수량", "마감 임박" (남용하면 신뢰가 떨어진다)
- 사이즈 도움: 사이즈 가이드 위치와 접근성

### 4.2 경쟁사 화면 기록 방법

한 번에 모든 화면을 모으기 어려우므로 정해진 화면 3개를 스크린샷으로 남긴다.

| 화면 | 기록 항목 |
| --- | --- |
| 홈 상단 | 배너 문구 유형, 쿠폰·혜택 표기 |
| 카테고리 목록 | 정렬 기본값, 필터 종류, 뱃지 |
| 인기 상품 상세 | 위 3.2 체크리스트 |

**검색광고 관측 방법**: 키워드 목록(예: "여성 의류 쇼핑몰", "30대 여성 쇼핑몰", "키작녀 쇼핑몰")을 정해 같은 시각에 일 n회 관측하고, 노출된 업체와 문구를 기록한다. 노출 점유 = 업체 노출 횟수 ÷ 전체 관측 횟수.

## 6. CRM 시나리오

자동화 메시지는 시점별로 목적이 다르다. 아래는 일반적인 구성이고 간격은 실험으로 조정한다.

| 시점 | 목적 | 예 |
| --- | --- | --- |
| 가입 즉시 | 첫 구매 유도 | 웰컴 쿠폰 |
| 장바구니 1시간·24시간 후 | 이탈 회수 | "담아 둔 상품이 곧 품절될 수 있어요" |
| 구매 후 3일 | 후기 유도 | 포토 후기 적립 |
| 구매 후 30일 | 재구매 유도 | 재구매 쿠폰 |
| 최종 구매 후 90일 | 휴면 방지 | 신상 안내 |
| 재입고 | 품절 알림 신청자 | 재입고 알림 |

**측정**: 시나리오별 열람률·클릭률·전환율·메시지 1건당 매출. **쿠폰이 없어도 구매했을 사람**에게 쿠폰을 주면 마진만 잃으므로, 쿠폰 받은 집단과 안 받은 집단을 비교(증분 실험)해서 효과를 확인한다.

## 7. 입점 경제와 손익

플랫폼 입점은 노출을 사는 대신 수수료를 낸다. 구조는 **판매 수수료, 결제 수수료, 광고비, 물류비**로 나뉜다. 플랫폼마다 조건이 다르고 계약마다 달라서 비율은 공개되지 않는 경우가 많다.

**입점 건당 손익 구조 예시값**

| 항목 | 금액 |
| --- | ---: |
| 판매가(쿠폰 적용 후) | 29,630원 |
| 플랫폼 판매 수수료(가정 25%) | −7,408원 |
| 상품 원가(가정 33%) | −9,778원 |
| 배송·포장(가정) | −3,000원 |
| 반품 손실(가정) | −1,000원 |
| **공헌이익** | **8,444원 (28.5%)** |

같은 상품을 자사몰에서 팔면 수수료 대신 광고비와 결제 수수료가 든다. 자사몰의 CAC가 입점 수수료보다 낮을 때만 자사몰이 이익이다.

**손익분기 비교**: 자사몰 CAC가 7,408원보다 낮으면 입점보다 자사몰이 낫다(수수료만 비교한 단순 모델). 재구매가 많은 고객은 LTV 관점에서 자사몰 가치가 더 크다.

**우리 DB에서 볼 수 있는 것**: 브랜드가 몇 개 플랫폼에 입점했고 자사몰이 있는지. 입점 브랜드가 자사몰을 병행하는 비율이 높으면 플랫폼 의존을 줄이려는 움직임일 수 있다.

## 8. 한국 규정 요점 (확인 후 적용)

일반적으로 알려진 요점이다. **적용 전에 최신 법령과 공정거래위원회 안내를 확인한다.**

| 영역 | 요점 | 우리 업무와의 관계 |
| --- | --- | --- |
| 통신판매업 신고 | 온라인에서 판매하려면 통신판매업 신고가 필요하다 | 공정위 집계의 출처이자 신규 진입 지표 |
| 청약철회 | 재화는 수령 후 7일 안에 철회할 수 있는 것이 기본이다(예외 있음) | 반품 정책 비교의 기준 |
| 표시·광고 | 허위·과장, 근거 없는 최저가·정상가 표시는 부당 표시가 될 수 있다 | 이중가격(소비자가) 표기 비교 시 주의 |
| 추천·보증 광고 | 협찬을 받은 게시물은 그 사실을 표시해야 한다 | 인플루언서 광고 관측 시 확인 기준 |
| 섬유제품 품질 표시 | 혼용률·취급 주의 등을 표시해야 한다 | PDP 정보 충실도 체크리스트 항목 |
| 개인정보 | 수집·이용·보관에 동의와 안전 조치가 필요하다 | 경쟁사 데이터 수집 시 개인정보는 모으지 않는다 |

## 9. 경쟁 신호 해석 가이드

신호가 보이면 하나의 원인으로 단정하지 않고 **가설을 여러 개 세운 뒤 확인**한다.

| 관측 신호 | 가능한 가설 | 확인 방법 |
| --- | --- | --- |
| 쿠폰률이 25% → 30%로 상승 | 시즌 전환 재고 정리, 대형 행사 대응, 신규 고객 확보 | 같은 시기 다른 몰의 변화, 신상 등록 수 변화 |
| 월 등록이 평소의 3배 | 시즌 일괄 등록, 촬영 몰아 올림 | 등록 카테고리 쏠림, 같은 날 등록 수 |
| 특정 카테고리 상품이 한꺼번에 판매중지 | 시즌 종료 정리, 공급 문제 | 같은 카테고리 신상 등록 여부 |
| 첫 화면 문구가 혜택형에서 감성형으로 | 포지셔닝 변화, 가격 경쟁 탈피 | 쿠폰률·가격대 동시 변화 |
| 무료배송 기준 금액 상승 | 객단가 올리기, 물류비 부담 | 같은 시기 상품 가격 변화 |
| 사이즈 범위 확장 | 신규 타깃 공략 | 타깃 키워드 변화, 모델 구성 변화 |
| 재입고 표기 상품 증가 | 인기 상품 반복 생산, 리오더 체계 | 재입고 간격 |

## 10. 시장 조사 방법

| 방법 | 용도 | 비고 |
| --- | --- | --- |
| 검색어 트렌드 | 키워드 수요 변화(예: 네이버 데이터랩, 구글 트렌드) | 상대값이므로 절대 건수가 아님 |
| 후기 텍스트 분석 | 불만·칭찬 주제 | 주제 분류와 감성 점수로 요약 |
| SNS 해시태그 | 스타일 유행 | 게시물 수 변화로 본다 |
| 설문 | 인지, 선호, 가격 수용 | 응답 표본 설계 필요 |
| 인터뷰 | 구매 이유, 불편 | 5~8명이면 주요 주제가 반복되기 시작한다는 것이 흔한 경험칙 |
| 공정위 신고 추이 | 신규 진입 규모 | 신고일 기준, 폐업·휴업과 분리 |

## 11. 사례에서 배우는 구조

공개 보도와 사례 연구로 알려진 구조이며, 세부 수치는 출처를 확인해야 한다.

| 사례 | 알려진 구조 | 배울 점 |
| --- | --- | --- |
| 자라(Zara) | 소량·빠른 회전, 수요 반응형 추가 생산 | 재고 위험을 줄이는 짧은 주기 |
| 쉬인(Shein) | 소량 시험 생산 후 반응에 따라 추가 생산 | 시험과 반복(test and repeat) |
| 무신사 | 브랜드 입점 플랫폼, 랭킹·큐레이션 | 플랫폼 노출 구조와 입점 의존 |
| 보세 쇼핑몰 | 자체제작·사입 병행, 신상 중심 | 소규모 몰의 신상 속도와 쿠폰 의존 |

## 12. 경쟁사 프로필 수집 체크리스트

한 몰을 처음 볼 때 수집할 항목과 찾을 위치다.

| 구분 | 항목 | 찾을 위치 |
| --- | --- | --- |
| 기본 | 상호, 대표 도메인, 사업자 정보 | 사이트 하단, 공정위 신고 |
| 상품 | 종류 구성, 상품 수, 신상 등록 월 | 카테고리·신상 목록 |
| 가격 | 가격대, 쿠폰, 소비자가, 끝자리 | 상품 목록·상세 |
| 사이즈 | 정책, 최대 치수, 실측 제공 | 상품 상세 |
| 프로모션 | 쿠폰·세일·무료배송 기준 | 홈, 이벤트 페이지 |
| 운영 | 배송비, 출고, 반품·교환, 혜택 | 정책 페이지 |
| 채널 | 자사몰, 입점 플랫폼, 앱, SNS | 사이트 링크, 플랫폼 검색 |
| 콘텐츠 | PDP 체크리스트 점수, 모델 스타일 | 상품 상세 |
| 신뢰 | 후기 수, 사업자 정보 정합성 | 상품 후기, 하단 정보 |

각 항목은 **수집일과 출처 URL**을 함께 남긴다.

## 13. 주의

- 지표는 정의가 같아야 비교된다. 쿠폰 적용 전·후, 건수·금액 기준을 먼저 맞춘다.
- 신호는 가설이다. 하나의 원인으로 단정하지 않는다.
- 법·규정 요점은 확인 후 적용한다.
- 공개 정보만 쓰고, robots.txt와 이용 약관을 지키며, 개인정보는 모으지 않는다.
- 클릭·체류·매출·광고비·재고량은 공개되지 않는다. 간접 신호로만 다루고 그렇게 표기한다.
