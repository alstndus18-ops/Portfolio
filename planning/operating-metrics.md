# 운영·기획에 쓰는 공개 정보 지표 설계

작성: 2026-10-28 · 기획서 [§8](korea-fashion-monitoring-plan.md) 모니터링 설계의 상세판. 판매량·매출은 다루지 않는다(§10-20).

## 0. 핵심 관점

- 판매량·매출·광고비·전환율·회원 전용 쿠폰은 얻을 수 없다. 리뷰 수나 품절로 판매를 추정하는 지표도 만들지 않는다.
- 대신 **무엇을, 얼마에, 언제, 어떤 구성으로 내놓는가**(공급 쪽 행동)는 모두 공개된다. 이것은 각 회사가 자기 내부 판매 데이터를 보고 내린 **결정이 겉으로 드러난 것**이다.
- 그래서 이 도구는 "남이 얼마나 팔았나"가 아니라 **"남이 어떤 결정을 했나"를 읽어 우리 결정의 근거·기준으로 쓰는 도구**다.
- 출발점은 정보를 많이 모으는 것이 아니라 운영자가 매주 내리는 결정(가격·할인·신상·재고·벤치마킹)이다.

## 1. 얻을 수 있는 정보와 위치

| 정보 | 어디서 | 비고 |
| --- | --- | --- |
| 상품명·정가·판매가·할인율 | 상품 목록, 상품 상세 | Cafe24 몰은 구조가 비슷해 `samples/similar-search/tools/collect.py` 재사용 가능 |
| 색·사이즈 옵션, 옵션별 품절·추가금 | 상품 상세 구매 옵션 | 이미 수집 코드 있음. 품절은 "지금 살 수 있는가" 정보로만 쓴다 |
| 소재·혼용률, 제조국, 치수, 세탁 방법 | 상품 상세(글자 또는 상세 이미지 속 표) | 전자상거래 상품정보제공 고시에서 의류는 소재·색상·치수·제조자·제조국 등을 표시해야 하므로 거의 모든 상품에 있다. 이미지 속 표는 OCR 필요 |
| 실측(총장·어깨·가슴·소매)과 모델 사이즈 | 상세 이미지·사이즈 표 | 글자 표면 쉽고, 이미지면 OCR |
| 출시일 | 직접 공개 안 됨 | **처음 발견한 날**로 대신한다(매일 저장해야 생김) |
| 카테고리 구조(메뉴) | 사이트 메뉴 | 메뉴 자체가 회사가 힘을 싣는 곳을 보여 준다 |
| 배송비·무료배송 기준·출고 기준·교환반품 비용 | 이용 안내·상품 상세 하단 | 자주 안 바뀌므로 월 1회 확인으로 충분 |
| 적립률·회원 등급 혜택 | 회원 혜택 안내(공개 페이지) | 로그인해야 보이는 쿠폰은 제외 |
| 메인 배너·이벤트·공지 | 메인 화면, 이벤트·공지 게시판 | 배너는 대부분 이미지라 OCR 필요 |
| 판매 채널(자사몰·플랫폼 입점) | 쇼핑몰·브랜드 DB 관계 데이터 | 이미 `research/fashion-commerce-map/data/curated/`에 있음 |
| 플랫폼 공개 랭킹·신규 입점 | 무신사·29CM·W컨셉·지그재그 공개 화면 | 순위는 플랫폼 노출 결정으로만 해석한다 |

얻을 수 없는 것: 판매량·매출, 광고비, 방문·전환율, 회원 전용 쿠폰·가격, 앱 전용 혜택, 인스타그램·카카오 채널 단독 혜택(사이트에 없으면 빠진다).

## 2. 4P로 본 지표

마케팅 기본 틀인 4P(McCarthy, 1960: Product·Price·Place·Promotion)로 나누면 빠짐없이 볼 수 있다.

### 2-1. 제품 (주 사용자: 기획 MD·디자이너)

**상품 구성의 폭과 깊이**
- 근거 이론: 상품 구성 계획(assortment planning, Kök·Fisher·Vaidyanathan, 2008). 폭(breadth)은 카테고리 수, 깊이(depth)는 카테고리 안의 상품 수와 색·사이즈 수다.
- 지표: 카테고리별 상품 수와 비중, 상품당 평균 색 수, 상품당 사이즈 수.
- 활용: "경쟁사는 니트 비중이 40%, 우리는 15%", "경쟁사는 한 디자인을 5색으로 깊게, 우리는 2색으로 얕게". 다음 시즌 구성 비율을 정하는 기준.

**색 비중의 변화**
- 지표: 시즌·월별 옵션 색 비중(35색 이름표 기준), 새로 늘어난 색, 줄어든 색.
- 활용: 디자이너의 시즌 컬러 기획 근거("이번 가을 비교군에서 버건디 옵션이 지난달보다 2배"). 색 이름 통일 사전은 `similar-search`에 이미 있다.
- 주의: 색 이름은 구매 옵션의 이름만 쓴다. 사진 모습으로 색을 지어내지 않는다.

**소재와 가격의 관계**
- 지표: 소재 구성(예: 울 30% 이상, 면 100%, 폴리 혼방)별 가격 중앙값과 범위.
- 활용: "울 30% 니트는 비교군에서 보통 4만~6만 원". 원가 대비 판매가 설정, 소재 선택의 기준. 소재 추출은 `samples/similar-search/material-data/`에서 진행 중이다.

**사이즈 실측과 범위**
- 지표: 아이템별 실측(총장·어깨·가슴·소매) 분포, 프리사이즈/S~XL/빅사이즈 비중, 모델 키·사이즈.
- 활용: 디자이너·생산의 핏 기준값("비교군 크롭 니트 총장 중앙값 48cm"). 사이즈 범위는 어떤 체형을 타깃으로 하는지 보여 주는 포지셔닝 정보다.

**디테일·실루엣 키워드의 확산**
- 근거 이론: 혁신 확산 이론(Rogers, *Diffusion of Innovations*, 1962), 패션 수명주기(Sproles, 1981: 도입→확산→정점→쇠퇴).
- 지표: 상품명 키워드(셔링·카라·크롭·벌룬 등)를 쓴 쇼핑몰 수와 상품 수의 주별 추이. 처음 쓴 곳과 퍼진 시점.
- 활용: 몇 곳에서 시작해 퍼지는 중이면 들어갈 시점, 이미 모두가 쓰면 포화라 피할지 판단. 상품명 키워드 사전은 `similar-search`에 이미 있다.

**경쟁사가 핵심으로 판단한 상품**
- 지표: 시즌을 넘겨 계속 파는 상품(캐리오버), 기존 디자인에 색을 추가한 상품, 재입고 표시가 붙은 상품, 메인·상단에 오래 고정된 상품.
- 활용: 판매 수치가 아니라 **경쟁사의 결정 그 자체**다. "이 회사는 이 디자인을 핵심으로 판단했다"는 근거.

**제조 표기**
- 지표: 자체제작(MADE) 표기 비중, 제조국 비중.
- 활용: 경쟁사의 소싱 전략(사입 위주인지 자체제작 위주인지, 국내 생산인지 해외 생산인지).

### 2-2. 가격 (주 사용자: 운영·기획 MD)

**가격 사다리**
- 근거 이론: 가격 단계 구성(price lining, 저가·중가·고가 good-better-best).
- 지표: 카테고리별 가격 구간(예: 1만 원 단위)마다 상품 수. 우리 상품을 같은 그림 위에 점으로 찍는다.
- 활용: 우리 가격의 위치, 아무도 없는 가격 구간(기회일 수도, 수요가 없는 곳일 수도 있으므로 판단은 사람이 한다).

**기준 가격과 할인 표기**
- 근거 이론: 준거가격(Thaler, 1985: 소비자는 기준이 되는 가격과 비교해 거래를 평가함), 앵커링 효과(Tversky·Kahneman, 1974).
- 지표: 할인 중인 상품 비율, 정가 대비 할인율 분포, 같은 상품의 정가 변경 여부.
- 활용: 늘 대부분을 할인하는 몰은 정가가 기준점 역할만 하는 것이다. 우리가 상시 할인형으로 갈지, 정가를 지키고 행사 때만 할인할지 정하는 근거.

**가격 끝자리 관행**
- 근거 이론: 끝자리 가격 효과(Schindler·Kibarian, 1996: 99로 끝나는 가격의 판매 반응 연구).
- 지표: 끝자리 분포(29,900원·29,000원·30,000원).
- 활용: 업계 관행 확인. 큰 결정은 아니지만 가격표 작성 기준이 된다.

**옵션 추가금 정책**
- 지표: 사이즈·색별 추가금이 있는 상품 비율과 금액.
- 활용: 빅사이즈 추가금 등 정책을 정하는 기준.

### 2-3. 판촉 (주 사용자: 운영 MD·마케팅)

**할인의 깊이·빈도·기간**
- 근거 이론: 판촉 연구의 기본 세 요소(Blattberg·Neslin, *Sales Promotion*, 1990).
- 지표: 행사별 할인율(깊이), 월 행사 횟수(빈도), 행사 일수(기간).
- 활용: "비교군은 월 2회, 평균 20%, 3일". 우리 행사 설계의 기준선.

**가격형과 비가격형 판촉**
- 지표: 할인·쿠폰(가격형)과 사은품·적립금·무료배송(비가격형)의 비중.
- 활용: 가격형은 정가 신뢰를 깎을 수 있다. 브랜드 가치를 지키면서 할 수 있는 판촉 방식을 고르는 근거.

**할인 들어가는 시점**
- 근거 이론: 패션 마크다운 이론(Pashigian, 1988: 유행의 불확실성이 클수록 할인이 많고 시즌 후반에 몰린다).
- 지표: 출시(처음 발견한 날)부터 첫 할인까지 걸린 일수, 할인 단계(10%→30%→50%), 세일 카테고리로 옮겨진 시점.
- 활용: 재고 처리 시점의 기준선("비교군은 출시 후 평균 6주에 첫 할인"). 매일 저장해야만 생기는 지표다.

**행사 캘린더**
- 지표: 시즌 행사(신학기·블랙프라이데이·연말·시즌오프) 시작일, 요일·시간대 패턴(타임세일), 월초·월급일 전후 패턴.
- 활용: 행사 시점 결정. 1년이 쌓이면 "작년 이맘때 누가 무엇을 했나"를 볼 수 있다.

**배너·메인 문구가 내세우는 것**
- 지표: 배너·메인 문구 키워드를 가격(할인·%)·신상·품질(소재·제작)·배송(당일출고)으로 분류한 비중.
- 활용: 경쟁사의 메시지 전략. 우리가 다르게 내세울 지점을 찾는다. 배너는 OCR이 필요해 정확도가 몰마다 다르다.

### 2-4. 유통·서비스 (주 사용자: 경영·운영)

**채널 구성**
- 지표: 자사몰만 하는지, 어느 플랫폼(무신사·29CM·W컨셉·지그재그·에이블리)에 입점했는지, 새로 입점한 채널.
- 활용: 채널 확장 판단의 근거. DB 관계 데이터를 그대로 쓴다.

**서비스 기준선**
- 지표: 무료배송 기준 금액, 기본 배송비, 출고 기준(당일 출고 마감 시각), 교환·반품 비용, 적립률, 회원 등급 혜택.
- 활용: "비교군의 무료배송 기준 중앙값 5만 원, 우리는 7만 원" 같은 업계 표준선.

## 3. 경영 관점: 우리는 어디에 서 있나

- **전략 그룹 지도**(Porter, *Competitive Strategy*, 1980): 가격대와 상품 구성 폭(또는 스타일·타깃) 두 축에 쇼핑몰을 배치한다. 같은 그룹이 직접 경쟁사이고, 빈자리는 기회 후보다.
- **경쟁 밀도**: 가격대·카테고리마다 업체 수.
- **시장의 움직임**: DB 확인일로 본 신규 진입·폐업 추이, 플랫폼 신규 입점.
- **말하는 방식**: 평균 대신 비교군 안의 순위·중앙값으로 말한다("우리 니트 가격은 비교군 상위 30%"). 평균은 튀는 값에 흔들린다.

## 5. 근거 자료로 쓰이게 하는 원칙

1. **출처**: 모든 숫자에 출처 주소와 확인일을 붙인다. 회의에서 근거로 쓰려면 눌러서 원본을 볼 수 있어야 한다.
2. **표기 통일**: 카테고리·색·소재·사이즈 이름을 같은 사전으로 맞춘다(색·상품명 키워드 사전은 이미 있음).
3. **비교군**: 비교군을 먼저 정하고 그 안의 중앙값·순위로 표시한다. 비교군 기준은 아직 미정(§10-6).
4. **매일 저장, 차이 기록**: 전체를 매일 쌓지 않고 바뀐 것(신상·가격 변경·할인 시작·품절·내림)만 기록한다. 출시일은 처음 발견한 날로 대신한다.
5. **시간이 자산**: 출시 주기·할인 시점·전년 대비 비교는 수집을 시작한 날부터만 쌓인다. 작게라도 빨리 시작한다.
6. **한계 표시**: 비교군 밖의 시장, 로그인·앱 전용 혜택, OCR로 못 읽은 배너는 모른다고 화면에 적는다.
7. **수집 예의**: 관심 업체만, 하루 한 번, 약관·robots.txt를 지키고 로그인을 우회하지 않는다. 화면 구조가 바뀌어 수집이 실패하면 실패했다고 표시한다.

## 7. 첫 단계 제안

비교군 10~20곳의 **기준값 카드** 한 페이지: 카테고리별 가격 중앙값, 할인 중인 상품 비율, 무료배송 기준, 사이즈 범위, 소재 비중, 주간 신상 수. 이후 순서는 상품 목록 매일 저장 → 신상 피드·경쟁사 비교표 → 주간 요약 → 행사 캘린더(처음엔 상품 할인율 변화로 대신) → 전략 그룹 지도·경쟁사 자동 추천.

시작 전에 정할 것: 기준이 되는 우리 브랜드, 비교군 10곳, 주력 카테고리.
