# 06. 한국 조사 카탈로그

이 문서는 앞으로의 상세 조사가 무엇을 대상으로 하고 어디까지 진행됐는지 일관되게 기록하기 위한 **마스터 목록**이다. 새 대상을 추가할 때는 먼저 아래의 수집 축과 카테고리를 고르고, 근거·확인일·상태를 남긴다.

## 1. 수집 축 — 무엇을 수집하는가

| 코드 | 수집 축 | 수집 단위 | 우선순위 | 현재 상태 |
| --- | --- | --- | --- | --- |
| AX-01 | 통신판매 신고 사업자 | 신고 사업자·상호·도메인·영업 상태 | 최상 | 진행 중 |
| AX-02 | 법인·그룹·사업부문 | 법인, 계열, 패션 사업부문, 공시 식별자 | 최상 | 진행 중 |
| AX-03 | 플랫폼·전문몰·편집숍 | 서비스·앱·웹몰·입점 구조 | 최상 | 진행 중 |
| AX-04 | 브랜드·D2C 자사몰 | 브랜드·브랜드 운영 주체·자사몰 | 최상 | 진행 중 |
| AX-05 | 판매 채널 관계 | 자사몰, 플랫폼 입점, 백화점 전문관, 해외 채널 | 높음 | 시작 전 |
| AX-06 | 리세일·중고·빈티지 | 서비스·검수·판매자/위탁 구조 | 높음 | 시작 전 |
| AX-07 | 오프라인 유통 연결 | 백화점·아울렛·플래그십·온라인몰 연결 | 중간 | 시작 전 |
| AX-08 | 물류·결제·광고·솔루션 | 패션 판매를 가능하게 하는 B2B 인프라 | 중간 | 시작 전 |
| AX-09 | 창작·도매·생산 생태계 | 디자이너·동대문·제조·도매·패션 특화 지원 | 중간 | 시작 전 |
| AX-10 | 해외 진출·역직구 | 글로벌 스토어·현지 법인·해외 마켓 관계 | 낮음(국내 구조 후) | 시작 전 |

### 축별 완료 기준

- `시작 전`: 수집 모수와 기준이 아직 확정되지 않음
- `진행 중`: 공식 출처 기반의 후보 목록과 첫 검증 데이터가 존재함
- `1차 커버`: 정한 모수를 한 차례 수집하고, 누락·보류 수를 기록함
- `정기 갱신`: 수집 주기, 기준일, 변경 이력까지 운영함

"완료"는 사용하지 않는다. 시장은 계속 변하므로, 각 축은 `정기 갱신` 상태를 목표로 한다.

## 4. 관계 카테고리 — 무엇과 무엇을 연결하는가

| 관계 | 출발 → 도착 | 예시 |
| --- | --- | --- |
| `operates` | 회사/사업부문 → 쇼핑몰·플랫폼 | 회사가 온라인 서비스를 운영 |
| `owns_or_operates` | 회사/사업부문 → 브랜드 | 자사 브랜드·운영 브랜드 |
| `sells_through` | 브랜드/판매자 → 채널 | 자사몰, 플랫폼, 전문관 판매 |
| `hosted_in` | 쇼핑몰/전문관 → 플랫폼/호스팅 주체 | 전문관·호스팅 관계. 운영·소유와 혼동 금지 |
| `parent_or_affiliate_of` | 회사 → 회사/사업부문 | 그룹·계열·사업부문 관계 |
| `has_category` | 브랜드/채널 → 상품 카테고리 | 골프, 여성복, 리세일 등 |
| `has_market` | 브랜드/채널 → 국가·시장 | 국내, 일본, 미국 등 판매 시장 |
| `uses_service` | 판매자/브랜드 → 인프라 | 물류·결제·광고·솔루션 사용 관계 — 공식 근거가 있을 때만 |

## 6. 매 수집 배치에 반드시 남길 기록

```text
배치 ID:
대상 백로그:
수집 기준일:
출발 모수 / 출처:
원본 행 수:
후보 수:
검증 완료 수:
보류·제외 수와 이유:
새로 만든 관계 수:
남은 누락 가설:
다음 재검토일:
```

이 기록이 쌓이면 나중에 화면에는 단순한 브랜드 목록이 아니라, **한국 패션 커머스가 어떤 사업 형태와 판매 채널로 구성되어 있는지**, 그리고 데이터가 어디까지 검증됐는지를 함께 보여줄 수 있다.
