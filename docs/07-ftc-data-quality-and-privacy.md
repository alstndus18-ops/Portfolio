# 공정위 통신판매 원본: 데이터 품질·개인정보 처리 원칙

## 목적

공정위 통신판매사업자 자료는 국내 온라인 판매 생태계의 지역별 **모수 단서**다. 그러나 이 프로젝트가 만들려는 것은 개인 판매자 명부가 아니라 패션 커머스 산업 구조 지도다. 따라서 원본은 수집하되, 공개 저장소와 웹 화면에는 비식별 집계와 검증된 기업·브랜드·서비스 관계만 싣는다.

패션 키워드 후보는 `취급품목`에 의류·패션·잡화·신발·가방·주얼리 등 정의된 단어가 포함된 레코드다. **패션 회사 수, 고유 브랜드 수, 실제 운영 중 사이트 수가 아니다.** 복수 품목 신고·중복 신고·폐업 상태·상호 변경과 사업자 단위 문제를 별도로 정리해야 한다.

## 원본이 비정형일 때의 처리

- 인용부호 속 쉼표·줄바꿈은 표준 CSV 규칙으로 해석한다.
- 17개 헤더 열과 필드 수가 다른 레코드는 열 밀림에 따른 오분류를 막기 위해 현 단계 집계에서 제외한다.
- 제외 수는 숨기지 않고 품질 지표로 공개한다.
- 비정형 레코드를 포함하려면 원문 보정 규칙·표본 검수·재현 가능한 버전을 별도로 만든다.

## 개인정보·표시 제한

다음 필드는 원본에 있더라도 파생 JSON, 웹 화면, Git 커밋 대상에서 제외한다.

- 대표자명
- 전화번호
- 전자우편
- 사업장 상세 주소·도로명 주소

원본 파일은 로컬 `data/raw/`에만 저장하고 `.gitignore`로 제외한다. 원본을 외부 공유하거나 개별 개인판매자 레코드를 화면에 노출하지 않는다.

## 재현

`scripts/analyze_ftc_mail_order.py`는 표준 라이브러리 CSV 파서로 개인정보 열을 출력하지 않는 집계 JSON만 만든다. 실행 전 원본 파일의 SHA-256과 수집일을 원본 인벤토리에서 확인한다.
