# 02. 출처 등록부

## 기록 원칙

출처를 링크 모음으로만 남기지 않는다. 무엇을 확인했는지, 언제 확인했는지, 재사용·수집에 어떤 조건이 있는지 남긴다.

## 출처 레코드 양식

| 필드 | 설명 |
| --- | --- |
| `source_id` | 예: `KR-FTC-001` |
| `title` | 출처 제목 |
| `publisher` | 제공 기관 또는 운영 주체 |
| `url` | 접근한 원본 링크 |
| `source_type` | 공시 / 공식 웹사이트 / 공개 등록부 / 보도자료 / 기타 |
| `accessed_at` | 확인한 일시 |
| `used_for` | 어떤 회사·브랜드·관계를 확인했는지 |
| `terms_or_notes` | 이용 조건, 지연 가능성, 불확실성 |

## 시작 출처 후보

| source_id | 출처 | 주 용도 | 상태 |
| --- | --- | --- | --- |
| KR-FTC-001 | 공정거래위원회 통신판매사업자 정보 | 신고 판매자·사업자 정보 확인 | 조사 전 |
| KR-DART-001 | 금융감독원 전자공시시스템(DART) | 상장사 및 공시 대상 기업의 법인·사업 정보 | 조사 전 |
| KR-OFFICIAL-001 | 각 회사·브랜드의 공식 웹사이트 | 운영 주체·브랜드·판매 채널 확인 | 대상별 추가 |

## 사용 중인 상세 출처

| source_id | 출처 | 제공자 | 원본 링크 | 출처 유형 | 확인일 | 사용 범위 | 주의 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| KR-FTC-003 | 통신판매사업자 자료 다운로드 | 공정거래위원회 | https://www.ftc.go.kr/www/selectBizCommOpenList.do?key=255 | 공개 등록부 | 2026-10-19 | 시·도별 통신판매 신고사업자 모수 파일 | 공개 원본에 개인사업자 정보가 포함될 수 있어 원본은 로컬 보관, 집계만 공개 |

## 주의

공개 등록 정보도 갱신 지연이나 누락이 있을 수 있다. 따라서 출처 하나만으로 단정하지 말고, 충돌 시 출처와 날짜를 나란히 남긴다.
