# 03. 분류 체계

분류는 처음부터 지나치게 세분화하지 않는다. 재현 가능한 수준으로 시작하고, 실제 조사에서 반복적으로 필요한 경우에만 확장한다.

- 가방·지갑
- 신발

## 가격대와 타깃

가격대나 핵심 타깃은 단정적 사실로 취급하지 않는다. 판단 기준, 근거, 확인 시점을 `notes`와 `Evidence`에 남기며, 불확실하면 비워 둔다.
